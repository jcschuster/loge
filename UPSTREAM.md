# Upstream

Changes Loge would take from the projects it builds on. Nothing waits on them: each
row names what Loge does without it. A row is ticked once its issue or pull request
is filed, with its state beside the tick, or once the change is released in a project
of this author's; `dropped` marks one Loge no longer needs.
